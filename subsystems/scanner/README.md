# scanner — 市场雷达

导演系统的选题前置模块。扫描目标平台排行榜，输出市场趋势和题材候选。

## 核心原则

- 单本排名不是结论，跨样本重复模式才是信号
- 番茄看流量+完读率，起点看订阅+追读
- 扫榜目标不是"什么最火"，而是"什么我能写且能火"

## 使用方法

```bash
python scripts/director_doctor.py --scan-target 番茄
```

## 输出格式

```yaml
平台: 番茄
热点题材:
  - 题材: 系统+争霸
    热度: 高 / 可写性: 需要差异化锚点
风险提示: 按需生成
```
