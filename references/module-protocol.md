# 模块协议

每个模块必须包含五个文件：

| 文件 | 内容 |
|---|---|
| guide.md | 模块解决什么问题，什么时候用 |
| rules.md | 输入、输出、触发条件、禁止事项、处理流程 |
| examples-good.md | 正例，最好来自真实项目 |
| examples-bad.md | 反例，说明为什么错 |
| sources.md | 来源索引：inkos / oh-story / Chinese-WebNovel / 项目经验 |

## 模块输出格式

模块输出必须包含：

```text
结论：PASS / WARN / FAIL
依据：引用文件/章节/状态
问题：如有，列出
建议：最多3条
下一步：继续 / 修复 / 停止
```

## 设计约束

- 模块只管自己的层，不越权。
- 模块可以请求读取其他文件，但不要重复保存真相。
- 主路由负责组合模块输出。
