# concept-gate：正例

## 例 1：副本刷怪差异化（PASS，78分）

```yaml
主角不可替代性: 9/10
  - 别人通了副本就走，主角可以在已通关副本里无限刷怪
  - 这个机制是世界观内置的 BUG，只有主角发现了

爽点可见性: 8/10
  - Ch1 发现 BUG → Ch2 验证 → Ch3 刷出一个稀有道具
  - 一刷一个爽，每章至少一个小收获

持续可写性: 8/10
  - 副本有 100 层，越往后越难
  - 每层新怪物、新道具、新玩法

市场匹配度: 8/10
  - 番茄游戏/系统文是稳定大类
  - 同类型《全球游戏：……》多本上榜

差异化锚点: 6/10
  - 差异："别人打完就没了，他打完了才开始"
  - 但这个点不是特别强，所以只给 6

金手指梯度: 8/10
  - 刷怪需要进入已通关副本，不能跳级
  - 越高级副本越难刷，不会一步登天
```

**为什么 PASS**：六维均衡，没有致命短板。最大风险是差异化不够强，但可以靠执行弥补。

## 例 3：《我在末日搞基建》（PASS，75分）

```yaml
主角不可替代性: 8/10
  - 别人都在杀丧尸，他在做城市规划
  - 他的优势是前世记忆——知道哪个地点有什么资源

爽点可见性: 7/10
  - Ch1-3 展示资源获取→庇护所建立→第一个投靠者
  - 爽点是"从零到有"的成就感，不是打脸

持续可写性: 9/10
  - 基建题材天然有无限扩展空间
  - 从庇护所→小镇→城市→国家

市场匹配度: 8/10
  - 末日+种田是番茄稳定品类

差异化锚点: 6/10
  - 和同类基建文的差异不够明显

金手指梯度: 7/10
  - 前世记忆随着时间推移会过时
  - 越到后期越需要自己的判断力
```

**为什么 PASS**：下限高（种田），上限可期（扩张），但差异化偏弱。
