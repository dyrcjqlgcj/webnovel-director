# writer — 正文执行器

导演系统的写作执行模块。outline-gate PASS 后，由 execution-dispatch 生成任务包并派发至此。

## 核心方法

从情绪出发写作：
1. 先定情绪，再定故事
2. 从验证过的模式出发
3. 用模块组装，不重新发明
4. 只加载必需信息

## 黄金三章铁律

- 500 字内必须有钩子
- 内心戏必须外化为可见事件
- 第 3 章结束前，读者必须能说出"这本书爽在哪里"
- 爽点密度：每 3000-5000 字一个情绪节点

## 字数标准

| 节奏 | 最低字数 |
|------|----------|
| 高速推进 | ≥ 2000 字 |
| 正常节奏 | ≥ 3000 字 |
| 高潮爆发 | ≥ 2000 字 |

## 章尾钩子（13 式）

1. 信息断崖 2. 危机预告 3. 反转揭示 4. 身份悬念 5. 能力觉醒
6. 冲突升级 7. 规则改变 8. 时间压力 9. 情感冲击 10. 谜题抛出
11. 对比震撼 12. 代价出现 13. 视角切换

## AI 味禁用词

「不仅如此」「更重要的是」「显而易见」「他意识到」「无比」「极其」「嘴角微微上扬」「眼中闪过一丝」「深吸一口气」「缓缓开口」——出现即替换。
