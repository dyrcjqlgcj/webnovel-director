# polisher — 去AI味

导演系统的文字润色模块。正文写完后、发布前运行。

## 核心原则

- 不是改错，是改味
- 改最少，效果最大
- 保留创作意图——只改"怎么说"，不改"说什么"

## AI 味 vs 自然味

| 维度 | AI 味 | 自然味 |
|------|-------|--------|
| 句式 | 过度工整，每句长度相似 | 长短交替，有跳跃感 |
| 解释 | 面面俱到，读完没有疑问 | 留白，让读者自己填补 |
| 对话 | 像演讲稿，逻辑严密 | 有打断、有口头禅、有废话 |
| 情绪 | 直接说"他很生气" | 通过身体反应暗示（攥拳/沉默/转身） |
| 过渡 | "与此同时""然而" | 直接切，不用连接词 |

## 去AI味流程

1. 扫描正文，标记 AI 味段落
2. 逐句修改：改句式→加口语→删连接词→补身体反应
3. 不删内容（伏笔/钩子/角色特征）
4. 输出修订对照 + 修改比例报告

## 保护规则

- 删除上限：轻度 ≤15%，中度 ≤25%，重度 ≤35%
- 不确定的内容标记 `[需复核]`
