# scanner — 市场雷达

导演系统的选题前置模块。在概念阶段之前，扫描目标平台（番茄/起点/晋江）排行榜，输出市场趋势和题材候选。

## 核心原则

- 单本排名不是结论，跨样本重复模式才是信号
- 番茄看流量+完读率，起点看订阅+追读
- 扫榜目标不是"什么最火"，而是"什么我能写且能火"

## 使用方法

导演工作流调用：
```bash
# 导演在概念阶段自动调用
python scripts/director_doctor.py --scan-target 番茄
```

也可手动触发扫榜，通过导演路由到外部 story-long-scan 获取详细数据。

## 输出格式

```yaml
平台: 番茄
扫描时间: 2026-05-23
热点题材:
  - 题材: 系统+争霸
    热度: 高
    上榜数: 12
    代表作: 《全球领主：……》
    可写性: 需要差异化锚点
  - 题材: 末世+基建
    热度: 中高
    上榜数: 8
    代表作: 《我在末世建城市》
    可写性: 高（市场稳定，竞争温和）
风险提示: 系统面板流已过度饱和，纯系统文不建议
```
