# polisher — 去AI味

webnovel-director 的文字润色子系统。正文写完后、发布前运行。不是改错，是改味。

## 核心原则

1. **不是改错，是改味**：AI 味是风格问题——过于书面化、过于对仗工整、过于面面俱到。
2. **改最少，效果最大**：能改一个词就不改一句，能删一句就不重写一段。
3. **保留创作意图**：只改"怎么说"，不改"说什么"。剧情、人设、情节走向一概不动。

## AI 味 vs 自然文本

> 自然文本基准：从热门网文中提炼的非模板化写作特征

| 维度 | AI 味 | 自然味 |
|------|-------|--------|
| 句式 | 过度工整，每句长度相似 | 长短交替，有跳跃感 |
| 解释 | 面面俱到，读完没有疑问 | 留白，让读者自己填补 |
| 对话 | 像演讲稿，逻辑严密 | 有打断、有口头禅、有废话 |
| 情绪 | 直接说"他很生气" | 通过身体反应暗示（攥拳/沉默/转身） |
| 过渡 | "与此同时""然而" | 直接切，不用连接词 |
| 段落 | 每段 4-6 句，整齐均匀 | 1-3 句为主，偶尔 1 句独占一行 |
| 对话标签 | 几乎每句都有"说道/问道" | 60%+ 无标签，用动作替代 |
| 比喻 | 文学化（"如寒冰般"） | 生活化（"像哈士奇护食"） |
| 结尾 | 总结/升华/感慨收尾 | 动作/对话收尾 |

## 检测流程

### Phase 1：AI 味扫描

扫描正文，标记 AI 味位置：

```
## AI味检测报告
AI味等级: 轻度 / 中度 / 重度
总体比例: X%
命中位置: [列出具体句子/段落]
```

### Phase 2：逐句修改

- 改句式 → 加口语 → 删连接词 → 补身体反应
- 不确定的内容标记 `[需复核]`，不强行修改
- 不删内容（伏笔/钩子/角色特征）

### Phase 3：输出修订对照

输出修改前后对比 + 修改比例报告。

## 保护规则

| AI 味等级 | 删除上限 | 处理方式 |
|-----------|----------|----------|
| 轻度 | ≤15% | 局部微调 |
| 中度 | ≤25% | 段落级改写 |
| 重度 | ≤35% | 合并重复描写 + 逐句重写 |

- 不得整段删除正文内容
- 删除前确认不破坏情节连贯性
- 非确定项标记 `[需复核]` 不计入删除比例
