# 转场模块运行规则

## 输入

必需：
- 待修正文片段
- 场景前后目标

建议读取：
- 章节任务包
- `truth/current_state.md`
- `director/last_audit.md`

## 检查维度

1. **场景因果**：上一场的结果是否自然导致下一场。
2. **情绪承接**：人物情绪是否有过渡动作/反应。
3. **信息释放**：是否用冲突承载信息，而不是说明书。
4. **对白目标**：每个说话者是否有目的。
5. **章末钩子**：是否来自本章变化，而非硬塞新事故。

## 输出

```text
结论：PASS / WARN / FAIL
依据：片段位置 + 章节目标
问题：转场/对白/钩子问题
建议：最多3条局部改法
下一步：保留 / 局部修 / 交回 chapter-review
```

## PASS

- 读者能理解场景为什么切换。
- 章末钩子承接本章变化。

## WARN

- 读感略跳，但不影响剧情理解。
- 对白略解释，可局部压缩。

## FAIL

- 场景之间无因果。
- 章末钩子与本章无关。
- 关键情绪被跳过导致人物行为失真。

## 禁止

- 禁止为了顺滑改变 premise 或章节目标。
- 禁止大幅重写整章；超过 30% 改动交 repair-feedback。
- 禁止只做文风润色而不解决转场问题。
