# writer — 正文执行器

导演系统的写作执行模块。在 outline-gate PASS 后，由 execution-dispatch 生成任务包并派发到此模块执行正文写作。

## 核心方法

从情绪出发写作，而非从灵感出发：
1. 先定情绪，再定故事
2. 从验证过的模式出发
3. 用模块组装，不重新发明
4. 只加载必需信息

## 黄金三章铁律

- 第 1 章 500 字内必须有钩子——不能从天气/风景开始
- 第 1 章以内心戏/独处开场 → 必须外化为可见事件（决定/误判/对话/物件变化）
- 第 3 章结束前，读者必须能清晰说出"这本书爽在哪里"
- 爽点密度：每 3000-5000 字一个情绪节点

## 字数标准

| 节奏 | 最低字数 |
|------|----------|
| 高速推进 | ≥ 2000 字 |
| 正常节奏 | ≥ 3000 字 |
| 舒缓铺垫 | ≥ 3000 字 |
| 高潮爆发 | ≥ 2000 字 |

## 章尾钩子（13 式）

1. 信息断崖：话说一半
2. 危机预告：危险即将来临
3. 反转揭示：原来你以为的是错的
4. 身份悬念：这个人是谁
5. 能力觉醒：主角将要获得/使用新能力
6. 冲突升级：矛盾激化到临界点
7. 规则改变：世界规则出现意外变化
8. 时间压力：倒计时开始
9. 情感冲击：关系出现重大转折
10. 谜题抛出：出现新的未解之谜
11. 对比震撼：主角的淡定 vs 他人的震惊
12. 代价出现：获得什么的同时失去了什么
13. 视角切换：切换到另一个角色看到关键信息

## 禁用词（AI 味一级警报）

以下词汇出现即替换：
- 「不仅如此」「更重要的是」「然而」「与此同时」「显而易见」
- 「他意识到」「他明白」「他清楚地知道」
- 「无比」「极其」「令人」「难以置信」
- 「嘴角微微上扬」「眼中闪过一丝」「心中涌起」
- 「深吸一口气」「缓缓开口」
