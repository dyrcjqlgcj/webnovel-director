# concept-gate：反例（来自实测）

以下反例全部来自 webnovel-director 实测定向中暴露的真实问题，已脱敏处理。

---

## 反例 1：信息型金手指无排他性（FAIL，35分）

```yaml
主角不可替代性: 2/10
  - 主角能看到别人的隐藏数值 → 但别人去公共设施也能查
  - 主角能交易该数值 → 所有人都能交易
  - 【致命伤】主角的"优势"没有排他性，只是早一步发现

爽点可见性: 3/10
  - 写了 5 章，读者反馈「没太明白主角的作用」
  - 交易本身不是爽点，是机制。爽点需要主角用信息差碾压别人，但前期没体现

持续可写性: 6/10
  - 交易设定本身有扩展性
  - 但核心优势太弱，中后期主角可能被任何有钱人替代

市场匹配度: 6/10
  - 系统+交易类有存在但无明确上榜对标

差异化锚点: 5/10
  - "隐藏数值交易"有点意思但不够强

金手指梯度: 2/10
  - 金手指本质上没有梯度——能看就能看，不能升级
```

**为什么 FAIL**：主角不可替代性崩溃。核心优势无排他性。

**改进方向**：让主角拥有别人**无法通过任何其他途径**获得的信息，或让他的交易有排他的信息优势。

## 反例 2：开局 SSR 级能力（FAIL，30分）

```yaml
主角不可替代性: 5/10
  - SSR 能力是随机获取的，理论别人也能拿到
  - 不是机制优势，是运气

爽点可见性: 7/10
  - 开局就强，爽是爽
  - 但反馈「金手指太大了，好像主角很快就可以无敌了」

持续可写性: 2/10
  - 开局满级，后续没有升级空间
  - 写完 20 章就没东西写了

市场匹配度: 6/10
  - 题材本身是热门

差异化锚点: 2/10
  - 「开局很强」不是差异，是模板

金手指梯度: 1/10
  - 没有梯度，一步登天
  - 【致命伤】读者在第 3 章就失去期待感
```

**为什么 FAIL**：金手指开局即巅峰。一步登天没有成长曲线。

**改进方向**：降级能力但有隐藏升级路径；或高级能力需要逐步解锁使用条件。

## 反例 3：纯观察者优势无机制支撑（FAIL，38分）

```yaml
主角不可替代性: 2/10
  - 每个人都能通过存活积累信息和经验
  - 「因为主角更耐心观察」→ 这是人设，不是机制
  - 读者反复追问「爽点在哪，主角优势是什么」

爽点可见性: 3/10
  - 「观察」不是可视爽点
  - 没有"每一个行动都有直接收获"的画面感

持续可写性: 7/10
  - 世界设定本身有扩展性

市场匹配度: 5/10
  - 有对标但不够强

差异化锚点: 2/10
  - 一句话说不清和同类有什么区别

金手指梯度: 5/10
  - 观察积累本身有梯度，但太慢太抽象
```

**为什么 FAIL**：主角优势不成立。"更耐心"是人设不是机制——换了别人也能做到。

**关键修复**：从"主角更耐心"升级为"主角拥有别人客观上不可能做到的机制能力"。例如从"观察不遗忘"升级为"死亡后记忆不灭"——别人死了等于白死，他死了等于情报采集。这是机制级而非人格级的差异。

## 反例 4：AI 上下文断裂生成无关概念（FAIL，0分）

```yaml
主角不可替代性: 6/10
  - 「比别人多一层信息视角」本身是成立的
  - 但【致命伤】这不是用户选的方向

爽点可见性: 6/10
  - 信息差是有效的爽点来源

持续可写性: 6/10
  - 可以分层升级

市场匹配度: 5/10
  - 信息差类有存在

差异化锚点: 5/10
  - 「系统多一行字」有点意思

金手指梯度: 6/10
  - 升级需消耗资源，梯度合理
```

**为什么 FAIL**：这是 AI 在执行用户选定方向的讨论时，自主偏离到的一个完全无关概念。不是概念质量不行，是**上下文断裂**——AI 放弃了用户选定的方向，自己生成了一个新方向。

这个问题属于 director 层面的上下文管理失败，不是概念本身的问题。在 concept-gate 中增加了「前提：此概念是用户当前选定的方向吗？」检查。

---

## 反例总结：四大死因

| 死因 | 代表案例 | 检测方法 |
|------|----------|----------|
| 主角优势无排他性 | 信息型金手指（例1） | 问：别人能做到一模一样的吗？ |
| 金手指一步登天 | SSR级开局（例2） | 问：50章后还有什么可写的？ |
| 爽点不可见 | 纯观察者优势（例3） | 问：第3章读者能说出爽在哪吗？ |
| AI 上下文断裂 | 无关概念（例4） | 问：这是用户选的方向吗？ |
