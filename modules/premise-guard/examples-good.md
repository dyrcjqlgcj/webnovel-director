# 命题防偏正例

## 例 1：拦截抢首通

待审细纲：主角组队正面击败 Boss，拿下全服首通。

```text
结论：FAIL
依据：premise 禁飞区「主角不能靠抢首通/正面推本兑现爽点」
问题：细纲把「别人通关我刷怪」改成了常规副本首通爽点。
建议：
1. 改为别人首通后副本残留怪物指数级刷新。
2. 主角利用复利机制吃掉被忽略的低级怪收益。
3. 首通队获得名声，主角获得隐藏长期收益，形成反差。
下一步：修复
```

## 例 2：WARN 不误杀

某章主要写配角视角，主角机制出现较少。

```text
结论：WARN
依据：本章无禁飞区，但核心机制露出不足
问题：如果下一章继续弱化主角刷怪复利，读者会感到换书。
建议：下一章必须用主角机制兑现一次可见收益。
下一步：继续，但写入 last_audit
```
