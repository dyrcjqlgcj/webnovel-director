# reviewer — 深度审查

导演系统的多视角审查模块。每章写完后自动触发，分三级：

## 审查分级

| Level | 频率 | 检查内容 |
|-------|------|----------|
| L1 | 每章 | 禁飞区扫描、命题贴合、字数、钩子 |
| L2 | 每 10 章 | 剧情逻辑、人物目标、情绪关系、伏笔 |
| L3 | 每 30 章/卷末 | 多 Agent 并行：命题+一致性+结构+伏笔 |

## L3 四 Agent 并行

1. **命题 Agent**：命题偏离 + 禁飞区
2. **一致性 Agent**：资源账/关系图/设定冲突
3. **结构 Agent**：钩子/对白/节奏/段落密度
4. **伏笔 Agent**：回收/新增/逾期

## 审查后流程

- PASS → 下一章
- WARN → 可选修复后继续
- FAIL → 进入 repair-feedback，不修复不继续
