# concept-gate：运行规则

## 触发条件

以下任一条件满足时触发：

1. 用户说「帮我选个题材」「有什么方向」「想写但不知道写什么」
2. 用户让 AI 生成多个概念提案供选择
3. 用户自己提出概念但未确认
4. director 在 Phase 1 扫榜后有多于 1 个候选方向

## 输入

必需（至少提供其中一项）：
- 一句话梗概（30 字以内）
- 书名（暂定也可）
- 核心金手指描述
- 目标平台（默认番茄）

建议提供：
- 对标书名（1-2 本）
- 预期字数
- 目标读者画像

## 六维审查

### 1. 主角不可替代性（权重：高）
检查：把主角换成另一个人，故事还能成立吗？

FAIL 条件：
- 主角的"优势"是所有人都可以做到的事
- 主角只是"更努力""更勤奋""更聪明"但没有机制性优势
- 例：「主角因为更耐心所以比别人强」→ 这是人设，不是金手指

PASS 条件：
- 主角拥有别人**客观上拿不到**的信息/能力/资源
- 这个优势与世界观机制绑定

### 2. 爽点可见性（权重：高）
检查：读者看到第三章结束时，能不能清晰说出"这本书爽在哪里"？

FAIL 条件：
- 爽点需要 30 章才能体现
- 爽点是"主角比谁都强"但这种强没有具体表现场景
- 例：「主角会越来越强」→ 所有网文都这样，这不是爽点

PASS 条件：
- Ch1-3 内有至少一个具体的、可视的爽点场景
- 这个场景可以被概括成一句话传播（「一觉醒来发现……」）

### 3. 持续可写性（权重：中）
检查：这个设定能撑 200+ 章吗？

FAIL 条件：
- 核心冲突只能撑 30 章（如"找到某个宝藏"）
- 力量天花板太低（如"成为世界第一"后没东西写了）
- 世界太窄（如"只有一间房间"的密室设定）

PASS 条件：
- 有明确的阶段性升级路径（≥4 个阶段）
- 每个阶段有不同对手/不同玩法/不同世界观层次

### 4. 市场匹配度（权重：中）
检查：目标平台上有同类书跑出来吗？

FAIL 条件：
- 平台搜索不到任何对标书名
- 题材是 2 年前的过期风口
- 题材需要大量前设知识（硬核科幻/历史考据）

PASS 条件：
- 在目标平台能找到 ≥2 本对标书（不要求一模一样，同类型即可）
- 题材有近期（3 个月内）上榜记录

### 5. 差异化锚点（权重：低）
检查：和已有对标书比，这本书有什么不一样的？

FAIL 条件：
- 找不到任何差异点
- 差异点是"写得更好"（这是执行，不是概念）

PASS 条件：
- 能一句话说清「和 XXX 的区别是 YYY」
- 差异有画面感，读者能直接想象

### 6. 金手指梯度（权重：高）
检查：金手指会不会让主角成长太快？

FAIL 条件：
- 金手指 = 直接无敌（开局就能秒杀一切）
- 没有明显的升级梯度，一步到位
- 例：「主角开局获得 SSS 级能力，碾压全场」

PASS 条件：
- 金手指有明确的使用限制/代价/冷却
- 成长曲线是「慢启动→加速→爆发」，而非「开局即巅峰」

## 评分公式

```
总分 = 
  主角不可替代性(25) + 爽点可见性(25) + 持续可写性(15) 
  + 市场匹配度(15) + 差异化锚点(10) + 金手指梯度(10)
```

每个维度 0-10 分。

## 输出

```text
结论：PASS / WARN / FAIL
总分：XX/100
各维度得分：{...}
风险清单：[...]
建议：[...]
市场参考：[...]
```

### PASS（≥70分）
→ 进入 premise-guard，开始写详细设定

### WARN（50-69分）
→ 标注风险点，用户确认后可以继续，但已知风险需写入 premise.md 的风险标记

### FAIL（<50分）
→ 拒绝。给出具体改进方向，建议重提 2-3 个修正版概念

## 禁止

- 禁止 WARN 后不标注风险就直接进入写作
- 禁止对 FAIL 概念做「优化一下就能过」的模糊承诺
- 禁止用「写得好的话也行」替代结构化审查
