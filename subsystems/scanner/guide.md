# scanner — 市场雷达

webnovel-director 的选题前置子系统。扫描目标平台排行榜，输出市场趋势和题材候选。

## 核心原则

1. **单本排名不是信号，跨样本重复模式才是**：必须从多个样本中提取共有特征。
2. **番茄看流量+完读率，起点看订阅+追读**：不同平台有不同的成功指标。
3. **扫榜目标不是"什么最火"，而是"什么我能写且能火"**：输出必须包含可写性评估。

## 扫榜流程

### Phase 1：确认平台和方向

- 用户已有方向 → 针对该方向做深度扫描
- 用户没有方向 → 全榜概览 + 趋势提取
- 用户想跨平台比较 → 平台对比分析

### Phase 2：数据采集

按优先级选择数据来源：

| 优先级 | 模式 | 说明 |
|--------|------|------|
| 1 | browser-cdp 采集 | 直接抓取平台页面，产出结构化文件 |
| 2 | 用户提供 | 用户粘贴榜单截图/文字 |
| 3 | 内置知识 | 基于知识库中的趋势数据做分析 |

#### 番茄平台采集

- 目标 URL：`fanqienovel.com/rank/1`（男频阅读榜）
- 核心字段：书名、作者、标签、在读人数、状态
- 男频 19 个子分类：西方奇幻/东方仙侠/科幻末世/都市日常/都市修真/都市高武/历史古代/战神赘婿/都市种田/传统玄幻/历史脑洞/悬疑脑洞/都市脑洞/玄幻脑洞/悬疑灵异/抗战谍战/游戏体育/动漫衍生/男频衍生

#### 起点平台采集

- 目标：热销榜 + 推荐票榜 + 月票榜
- 核心字段：书名、作者、订阅数据、追读率、字数、更新频率

### Phase 3：信号提取

从采集数据中提取：
1. **高频题材**：出现 ≥3 次的题材/标签组合
2. **跨平台重复模式**：在多个平台同时出现的题材信号（信号更强）
3. **上升趋势**：最近 30 天排名快速上升的题材
4. **饱和风险**：同题材在榜过多（>5 本）→ 竞争激烈

### Phase 4：输出报告

```yaml
平台: 番茄
样本日期: 2026-05-25
信号强度: 高/中/低
热点题材:
  - 题材: 系统+争霸
    热度: 高
    可写性: 需要差异化锚点
    样本数: 3/10
    饱和风险: 中
  - 题材: 玄幻+系统+养成
    热度: 高
    可写性: 适合新人
    样本数: 2/10
    饱和风险: 低
风险提示:
  - 无系统未上榜 → 蓝海但需教育市场
下次复扫: 2026-06-01
```

## 短篇 vs 长篇扫榜差异

| 维度 | 短篇 | 长篇 |
|------|------|------|
| 平台 | 盐言/七猫/黑岩/点众 | 番茄/起点/晋江 |
| 关键指标 | 完读率 + 传播率 | 追读率 + 订阅 |
| 风口周期 | 数周内可能失效 | 数月内稳定 |
| 情绪优先级 | 单情绪体验 | 多情绪周期 |
