# reviewer — 深度审查

导演系统的多视角审查模块。在每章写完后自动触发，分三级：

## 审查分级

| Level | 频率 | 检查内容 |
|-------|------|----------|
| L1 快速筛查 | 每章 | 禁飞区扫描、命题贴合、字数、钩子 |
| L2 普通审查 | 每 10 章 | 剧情逻辑、人物目标、情绪关系、伏笔 |
| L3 深度审查 | 每 30 章/卷末 | 多 Agent 并行：命题+一致性+结构+伏笔 |

## L1 审查标准

- 禁飞区：正文是否出现 premise 禁止的套路
- 命题贴合：本章是否兑现了书名承诺
- 字数：是否达到目标字数 90%
- 钩子：章末是否有下一章的阅读动机

## L2 审查标准

- 剧情逻辑：因果链是否完整
- 人物目标：每个主要角色是否有明确动机
- 情绪关系：关系是否按设定推进
- 伏笔：pending hooks 是否推进或回收

## L3 审查标准（多 Agent 并行）

4 个子 Agent 同时审查：
1. **命题 Agent**：命题偏离 + 禁飞区
2. **一致性 Agent**：资源账/关系图/设定冲突
3. **结构 Agent**：钩子/对白/节奏/段落密度
4. **伏笔 Agent**：回收/新增/逾期

## 审查后流程

- PASS → 进入下一章
- WARN → 可选修复后进入下一章
- FAIL → 进入 repair-feedback，不修复不继续
